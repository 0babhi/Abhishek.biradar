# Abhishek Biradar — GitHub Portfolio

A responsive GitHub Pages portfolio for Cloud Operations / AWS / Infrastructure work.

## Files
- `index.html` — portfolio content
- `style.css` — responsive dark theme
- `script.js` — mobile navigation and project filtering

## Publish on GitHub Pages

1. Open the repository that currently serves `https://0babhi.github.io/Abhishek.biradar/`.
2. Back up the existing `index.html`.
3. Replace the existing site files with these three files.
4. Commit and push to the branch configured for GitHub Pages.
5. Open the site and hard-refresh the browser.

## Before publishing
Update:
- Email address in `index.html`
- LinkedIn URL if you want it added
- Any project repository URLs
- Project screenshots, if you want visual case studies
- Experience dates/company wording if you want the timeline to be more specific

The portfolio deliberately distinguishes hands-on projects from production/operations experience.
